1. **终端 agent 正在分成三类角色**：模型厂商的官方入口（gemini-cli）、自主执行（OpenHands）、agent 运行时（herdr）。

## 01 终端成为 AI coding 的主界面

### Google Gemini CLI `v0.66.0`

- **变化**：本周发布 0.66 版本。它是 Google 把 Gemini 直接放进终端的官方 agent 入口。
- **证据**：2026-10-27 发布；108,624 stars；topics 包含 `cli`、`ai-agents`、`mcp-client`、`mcp-server`。
- **对你的意义**：如果你已经在终端里用 agent，这是目前最接近「厂商官方终端入口」的项目；和你在用的 Claude Code 属于同一层，差异在模型和 MCP 生态。
- **行动**：**值得试**。npm 全局安装，估计 2 分钟；需要一个 Gemini API key。

### OpenHands `v1.34.0`

- **变化**：本周发布 1.34 版本，定位是「AI 驱动的开发」——不只是补全，而是自主执行任务。
- **证据**：2026-10-27 发布；92,230 stars；最近推送就在今天。
- **对你的意义**：和 Gemini CLI 相比，它更偏「让 agent 自己跑任务」，权限模型会更激进。如果你在评估自动化的边界，可以把它当作对照组。
- **行动**：**观望**。自主执行对权限和沙箱要求高，先看它在你的项目里怎么写文件、怎么跑命令。

### Continue（候选）

- **变化**：证据包里排进 CLI 分组的新候选，开源 coding agent，今天仍在推送。
- **证据**：36,372 stars；TypeScript；topics 包含 `agent`、`cli`、`developer-tools`。
- **对你的意义**：它是开源、可自托管的双端 agent（IDE + 终端）。如果你在意「agent 完全跑在自己的环境里」，这个方向比厂商入口更可控。
- **行动**：**观察**。把它和 Gemini CLI 放在一起比较权限模型。

### herdr `v0.9.5`

- **变化**：10-14 发布小版本。它的定位是「coding agents 生活的运行时」——一个面向多 agent 的终端复用器。
- **证据**：46,709 stars；Rust；topics 包含 `terminal-multiplexer`、`agent-orchestration`。
- **行动**：**观望**。如果你同时跑多个 terminal agent，这是值得关注的工作流层。

**本期判断**：终端 agent 的竞争已经从模型能力转向三件事——权限边界、可观测性、和多 agent 的协作方式。

## 02 Token 成本开始被工程化

### rtk `v1.1.0`

- **变化**：本周发布 1.1 版本。它是一个 CLI 代理，把常见开发命令的 LLM token 消耗降低 60–90%。
- **证据**：2026-10-25 发布；85,017 stars；Rust；topics 包含 `token-optimization`、`cost-reduction`、`command-line-tool`。
- **对你的意义**：你每天在终端里跑大量命令，如果这些命令的输出会进入 agent 上下文，rtk 这类代理比「换更便宜的模型」更直接。
- **行动**：**值得试**。单二进制，估计 1 分钟安装；先拿一周的真实命令统计节省量。

**上下文**：上一期提到过的 Caveman（压缩 65%）和 ECC（harness 优化）是同一个方向——成本优化正在从「模型层」下沉到「上下文层」。如果你只挑一个试，rtk 的收益最可量化。

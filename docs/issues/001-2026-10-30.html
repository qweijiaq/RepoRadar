01

Agent 平台从「搭」到「交付」

这周的两个版本指向同一个方向：竞争点已经不是「能不能搭起来」，而是「能不能部署、治理、观测」。

Dify159,956 stars · Python

变化1.18 把 Agent 路由、可移植应用和工作流可观测性做进核心。这三件事都不是编排能力，而是「交付」能力。
证据v1.18.0，2026-10-23 发布，release 标题是 Smarter Agent Routing, Portable Apps, Deeper Workflow Visibility；最近一次推送就在今天。
对你的意义你 star 的项目里 agent 工具占多数。Dify 正从「低代码编排」转向「可交付的应用运行时」，如果你在自建 agent 平台，这一版的路由层值得和自己的方案对照。它和 LangChain 更接近替代关系。
行动值得试 Docker Compose 启动，估计 5–10 分钟（本机尚未验证）。

Paperclip108,746 stars · TypeScript

变化继续强化 agent 治理、项目管理和多 agent 协作。版本号 v2026.1023.0 就是日期，说明迭代节奏很快。
证据2026-10-24 发布；topics 包含 agent-orchestration、ai-governance、project-management。
对你的意义它和 ECC 正好互补——ECC 优化 agent 自身（skills、memory、security），Paperclip 管 agent 团队。如果你在考虑「多个 agent 怎么协作」，这两个项目可以放在一起看。
行动观望 定位清晰，但版本还很早期，适合先收藏。
判断：如果你在选型，优先看部署、治理、可观测这三项，而不是再看一遍框架能力表。
02

自托管推理层，一周三更

如果你在自托管，这是一个自然的升级窗口：三个组件在十天内先后发布了版本。

三个版本，同一个信号

vLLMv0.32.0（10-18）· 服务端推理引擎的大版本迭代。
Ollamav0.40.13（10-28）· 本地模型列表已经覆盖 Kimi、GLM、MiniMax、DeepSeek、gpt-oss、Qwen、Gemma。
Open WebUIv0.12.5（10-29）· 自托管 UI 同步更新。
Transformersv5.22.0（10-29）· 加入 Mistral Large 4 支持，模型定义层在同步跟进。
对你的意义三者的分工越来越清晰——Ollama 面向本地开发，vLLM 面向吞吐和服务端，Open WebUI 是门面。如果你准备自托管，这周是升级窗口。
行动试 Ollama 0.40.13 观望 vLLM 0.32 大版本变化，先读 release notes 再升级。
03

上下文工程成为新战场

token 效率、代码知识图谱、技能分发，本质上都在解决同一个问题：怎么让 agent 在有限上下文里看到对的东西。

Graphify138,884 stars · Python

变化把代码库、文档、SQL schema、配置和 PDF 变成可查询的知识图谱，作为 Claude Code、Cursor、Codex、Gemini 的技能使用。
证据v0.9.97，2026-10-27 发布；topics 覆盖 tree-sitter、graphrag、knowledge-graph、MCP。
行动值得试 如果你经常让 agent 读大仓库，这是本周最贴近你工作流的项目。

Caveman116,153 stars · Go

变化用「山顶洞人说话」的方式给 coding agent 降低 65% token 消耗，是一个病毒式传播的技能 + 代理。
证据最近一次推送 10-29；描述直接写着 “Viral skill + proxy for coding agents”。
行动当实验看 可以了解 token 压缩思路，不要当工程实践。

rea408,880 stars · TypeScript

变化用 agent 做逆向工程，从应用行为一路分析到原生二进制。
行动可忽略 垂直场景，除非你做安全或逆向。

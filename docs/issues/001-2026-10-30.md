## 01 Agent 平台从「搭」到「交付」

### Dify 1.18：把「可移植应用」做进核心

- **变化**：1.18 版本的重点是 Agent 路由、可移植应用和工作流可观测性——这三件事都不是编排能力，而是「交付」能力。
- **证据**：`v1.18.0`，2026-10-23 发布，release 标题是 *Smarter Agent Routing, Portable Apps, Deeper Workflow Visibility*；仓库 159,956 stars，最近一次推送就在今天。
- **对你的意义**：你 star 的项目里 agent 工具占多数。Dify 正从「低代码编排」转向「可交付的应用运行时」，如果你在自己搭 agent 平台，这一版的路由层值得和自己的方案对照。它和 LangChain 更接近替代关系，而不是互补。
- **行动**：**值得试**。Docker Compose 启动，估计 5–10 分钟（本机尚未验证）。

### Paperclip：把 agent 当同事管理

- **变化**：`v2026.1023.0`（10-24）继续强化 agent 治理、项目管理和多 agent 协作。版本号就是日期，说明迭代节奏很快。
- **证据**：108,746 stars；topics 里有 `agent-orchestration`、`ai-governance`、`project-management`。
- **对你的意义**：它和 ECC 正好互补——ECC 优化 agent 自身（skills、memory、security），Paperclip 管 agent 团队。如果你在考虑「多个 agent 怎么协作」，这两个项目可以放在一起看。
- **行动**：**观望**。定位清晰，但版本还很早期，适合先收藏。

### 本期判断

这周的两个版本指向同一个方向：agent 产品的竞争点，已经从「能不能搭起来」转向「能不能部署、治理、观测」。如果你在选型，优先看这三项，而不是再看一遍框架能力表。

## 02 自托管推理层，一周三更

- **vLLM `v0.32.0`**（10-18）：服务端推理引擎的大版本迭代。
- **Ollama `v0.40.13`**（10-28）：本地模型列表已经覆盖 Kimi、GLM、MiniMax、DeepSeek、gpt-oss、Qwen、Gemma。
- **Open WebUI `v0.12.5`**（10-29）：自托管 UI 同步更新。
- **Transformers `v5.22.0`**（10-29）：加入了 Mistral Large 4 支持，模型定义层在同步跟进。

**对你的意义**：如果你准备自托管，这周是一个自然的升级窗口。三者的分工也变得清晰——Ollama 面向本地开发，vLLM 面向吞吐和服务端，Open WebUI 是门面。

**行动**：**试 Ollama 0.40.13**（升级成本低，覆盖的模型更多）；**观望 vLLM 0.32**（大版本变化，先读 release notes 再升级）。

## 03 上下文工程成为新战场

- **Graphify `v0.9.97`**（10-27）：把代码库、文档、SQL schema、配置和 PDF 变成可查询的知识图谱，作为 Claude Code、Cursor、Codex、Gemini 的技能使用。138,884 stars。
- **Caveman**：用「山顶洞人说话」的方式给 coding agent 降低 65% token 消耗，116,153 stars，最近一次推送在 10-29。
- **rea**：用 agent 做逆向工程，从应用行为一路分析到原生二进制。408,880 stars，今天仍在推送。

**判断**：竞争正在从「模型和框架」转向「上下文和技能」。token 效率、代码知识图谱、技能分发，本质上都在解决同一个问题：怎么让 agent 在有限上下文里看到对的东西。

**行动**：**试 Graphify**（如果你经常让 agent 读大仓库）；**把 Caveman 当成 token 成本实验**，不要当工程实践；**rea 属于垂直场景**，除非你做安全或逆向，否则可以忽略。
